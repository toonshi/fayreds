# Fayreds Travel logo files

| File | Use it for |
|---|---|
| `fayreds-travel-logo.svg` / `.png` | Main logo on light backgrounds (website, documents, email signature) |
| `fayreds-travel-logo-white.svg` / `.png` | On dark or photo backgrounds (the icon keeps its colours) |
| `fayreds-travel-icon.svg` | The sun-over-the-ocean icon on its own: profile pictures, app icons, stickers |
| `fayreds-travel-icon-1024.png`, `-512.png`, `-192.png` | Same icon as PNG (social profile pictures, WhatsApp Business, favicons) |

- SVG files scale to any size without blurring; the lettering is converted to shapes, so no font needs to be installed.
- PNGs have transparent backgrounds. The full logo PNG is 2400px wide.
- Colours: teal `#0f4c4a`, sunset amber `#f2a541`, sea green `#7fc9bf`, sand `#fbf8f3`. Typeface: Fraunces Bold.
- "Fayreds Travel" is one name: keep it on one line and don't stack or separate the words.
